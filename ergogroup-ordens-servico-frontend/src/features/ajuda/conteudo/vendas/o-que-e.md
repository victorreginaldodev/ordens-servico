## O que tem numa venda

- **Cliente e venda:** para quem foi vendido, a data da venda e a prioridade. Quem vendeu é preenchido sozinho.
- **Serviços vendidos:** cada serviço é escolhido do catálogo, com uma descrição do que será feito.
- **Condição de pagamento:** o valor e como o cliente vai pagar. Só aparece para quem vê valores.

## Cada serviço vai para um setor

O catálogo diz qual setor executa cada serviço. Ao registrar a venda, cada serviço vai sozinho para a fila do setor certo. Uma mesma venda pode ter serviços de vários setores.

> [!DICA] Mudou o setor no catálogo?
> Os serviços já vendidos continuam no setor em que entraram. Só as vendas novas vão para o setor novo.

## O caminho de uma venda

```fluxo
Venda registrada
Setores recebem
Serviços executados
Liberada para faturar
Faturada
```

Quando o financeiro registra o faturamento, quem vendeu recebe um e-mail avisando que a OS foi faturada.
